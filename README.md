# Anime Fan v9 — Mobile Complete Reference

This version expands the design to match the supplied mobile reference across the main screens:
Home, Anime, Anime Details, Watch, My List, Movies, Genres, Trending, Search, Anime Request, Admin Login, Admin Dashboard, Add Anime, Manage Episodes and Mobile Menu.

GitHub Pages: upload all files to the same branch root. `app.js` contains the bundled local artwork used by the design preview. No image folder is required.

Firebase, real database, authentication, comments and authorized video provider integration are intentionally left for the next phase.
