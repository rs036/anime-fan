# Anime Fan Website

A responsive anime discovery UI built from the supplied Anime Fan screenshot as the visual reference and the public aniflix.uno site as a feature/data-structure reference.

## Included
- Desktop + mobile responsive layout
- Sidebar navigation
- Search UI
- Hero / featured section
- Trending anime cards
- Continue Watching
- Movies / Dubbed / Genres / Upcoming / Top Rated shortcuts
- Popular Categories
- Currently Watching
- Top 10
- Next Episodes
- Anime Calendar
- My List stored in localStorage
- Demo episode player modal

## Important
The player is intentionally a demo placeholder. For a production site, connect a lawful/licensed video provider or your own content source. The public Aniflix API documentation exposes anime discovery and watch endpoints, but you should verify its terms and content rights before integrating it.

## Run
Open `index.html` in a browser, or deploy the folder to Netlify / Vercel / GitHub Pages.
